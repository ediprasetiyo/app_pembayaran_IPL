## 4. DESKRIPSI LAYANAN (untuk field "Business Description")

### Singkat (1 paragraf):
```
IPL Griya Pesona Madani adalah aplikasi mobile (Android) untuk memudahkan warga
Perumahan Griya Pesona Madani Tenjo melakukan pembayaran Iuran Pemeliharaan Lingkungan
(IPL) bulanan dan uang kedukaan. Aplikasi dikelola oleh pengurus RT untuk keperluan
administrasi komunitas (non-komersial). Pembayaran diproses via Midtrans dengan
mata uang Rupiah, ditampilkan in-app (tidak diarahkan ke website eksternal).
```

### Detail (untuk field deskripsi panjang):
```
Aplikasi IPL Griya Pesona Madani menyediakan layanan administrasi keuangan komunitas
perumahan, mencakup:

1. PEMBAYARAN IPL BULANAN
   Warga membayar Iuran Pemeliharaan Lingkungan setiap bulan via berbagai metode
   (Virtual Account BCA/BNI/BRI/Permata/Mandiri, GoPay, ShopeePay, DANA, QRIS,
   Kartu Kredit, Indomaret, Alfamart, dll). Nilai tagihan diatur oleh pengurus RT
   (rata-rata Rp 65.000/warga/bulan).

2. PEMBAYARAN UANG KEDUKAAN
   Iuran sekali bayar untuk dana santunan warga yang berduka. Nilai Rp 20.000/warga.
   Saldo dipakai untuk membantu warga yang mengalami musibah keluarga.

3. ADMINISTRASI WARGA
   Pengelolaan data warga, anggota keluarga, status hunian, dan riwayat transaksi.

4. KOMUNIKASI KOMUNITAS
   Pengaduan warga ke pengurus RT, pengumuman & berita komunitas, notifikasi reminder
   pembayaran otomatis via Firebase Cloud Messaging.

Aplikasi ini bersifat NON-KOMERSIAL. Pengelola tidak mengambil profit dari transaksi —
seluruh dana yang masuk digunakan kembali untuk kepentingan warga (operasional RT,
sampah, keamanan, kebersihan, dll).

Halaman pembayaran ditampilkan di dalam aplikasi mobile (in-app WebView Snap Midtrans),
TIDAK diarahkan ke website pihak ketiga. Semua transaksi menggunakan mata uang Rupiah (IDR).
```

## 12. SETELAH APPROVED

Setelah Midtrans approve Production:

1. Login Midtrans Dashboard → switch ke **Production mode**
2. Settings → **Access Keys** → copy Server Key & Client Key (yang Production)
3. cPanel File Manager → edit `/home/dszgofcr/ipl-backend/.env`:
   ```env
   MIDTRANS_SERVER_KEY=Mid-server-XXXXXXXXXXX
   MIDTRANS_CLIENT_KEY=Mid-client-XXXXXXXXXXX
   MIDTRANS_IS_PRODUCTION=true
   ```
4. Akses `deploy.php` untuk clear cache
5. Midtrans Production Dashboard → Settings → **Configuration → Notification URL**:
   ```
   https://ipl-griya-pesona-madani.my.id/api/v1/ipl/midtrans/callback
   ```
6. Test dengan 1 transaksi kecil (e.g., Rp 1.000) menggunakan e-wallet asli (GoPay/QRIS)
7. Verifikasi: pembayaran sukses → notif FCM masuk → tagihan jadi Lunas di backoffice
8. **LIVE! 🎉** — warga bisa bayar real money sekarang
