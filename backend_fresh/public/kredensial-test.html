3. SKENARIO TEST TRANSAKSI

A. Pembayaran via Mobile App (Warga)

  1. Install APK di HP Android
  2. Buka aplikasi → tunggu splash screen
  3. Login dengan kredensial warga di atas (082115525327)
  4. Tab Pembayaran → tagihan IPL bulan ini tampil
  5. Klik tombol "Bayar"
  6. Muncul modal pilih metode pembayaran (VA, GoPay, ShopeePay, DANA, QRIS, dll) beserta biaya admin per metode
  7. Pilih metode (e.g., GoPay / QRIS untuk paling cepat)
  8. Snap UI Midtrans terbuka di dalam aplikasi (in-app WebView), TIDAK redirect ke browser eksternal
  9. Selesaikan pembayaran (di Sandbox: gunakan Midtrans Payment Simulator)
  10. Notifikasi push muncul di HP: "Pembayaran IPL Berhasil"
  11. Tab Pembayaran > Riwayat — transaksi tampil dengan logo brand & status "Lunas"

B. Verifikasi di Back Office (Super Admin)

  1. Login Back Office dengan kredensial super admin
  2. Dashboard — angka "Total IPL" bertambah
  3. Pembayaran — transaksi baru muncul dengan order_id Midtrans
  4. Audit Log — entry "payment_success" tercatat
  5. Laporan → Export Excel atau PDF
