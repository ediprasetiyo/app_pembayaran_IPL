Kebijakan Privasi

Berlaku efektif 20 Mei 2026

Kami menghargai privasi Anda. Kebijakan ini menjelaskan bagaimana aplikasi IPL Griya Pesona Madani Tenjo mengumpulkan, menggunakan, dan melindungi informasi pribadi pengguna.

1. Data yang Dikumpulkan

Saat Anda menggunakan aplikasi ini, kami dapat mengumpulkan data berikut:

  • Data identitas: nama lengkap, nomor telepon, email (opsional), foto profil
  • Data hunian: blok, nomor rumah, status hunian (milik/sewa/kontrak)
  • Data keluarga: anggota keluarga yang tinggal di hunian (nama, hubungan, jenis kelamin)
  • Data transaksi: riwayat pembayaran IPL & kedukaan, metode pembayaran, status
  • Data teknis: FCM token (untuk notifikasi push), IP address, info perangkat

2. Tujuan Penggunaan Data

  • Mengelola data warga RT untuk administrasi perumahan
  • Memproses pembayaran IPL & uang kedukaan
  • Mengirim notifikasi reminder pembayaran & pengumuman
  • Memberikan bantuan teknis & customer support
  • Audit & pencegahan fraud / penyalahgunaan

3. Pihak Ketiga

Data pembayaran (nominal, metode) ditangani oleh PT. Midtrans sebagai payment gateway resmi berlisensi Bank Indonesia. Midtrans memiliki standar keamanan PCI-DSS. Selain Midtrans, data tidak dibagikan ke pihak ketiga kecuali diwajibkan oleh hukum yang berlaku di Indonesia.

Foto/gambar (avatar, foto pengaduan, gambar berita) disimpan di Cloudinary sebagai content delivery network (CDN). Foto hanya bisa diakses oleh user yang berhak (warga & admin).

Notifikasi push dikirim via Firebase Cloud Messaging (Google).

4. Keamanan Data

  • Password disimpan ter-enkripsi (bcrypt hash)
  • Komunikasi via HTTPS (SSL/TLS)
  • Token akses berbasis Laravel Sanctum dengan expire policy
  • Audit log untuk semua aksi penting (login, perubahan data, transaksi)
  • Data pembayaran tidak disimpan di server kami — semua diproses Midtrans

5. Hak Pengguna

  • Hak akses: melihat data pribadi Anda di menu Profil aplikasi
  • Hak koreksi: mengubah data pribadi (nama, foto, email)
  • Hak penghapusan: meminta penghapusan akun via admin (kecuali data transaksi yang wajib disimpan untuk audit RT)
  • Hak menolak notifikasi: mematikan notifikasi push di pengaturan HP

6. Cookie & Tracking

Aplikasi mobile tidak menggunakan cookie. Backoffice (web admin) menggunakan localStorage untuk menyimpan token login & preferensi tema. Tidak ada tracking analytics dari pihak ketiga.

7. Penyimpanan Data

Data disimpan di server IDcloudHost (Indonesia) selama akun aktif. Data riwayat transaksi tetap disimpan untuk keperluan audit RT meskipun akun nonaktif, sesuai musyawarah pengurus.

8. Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui sewaktu-waktu. Perubahan akan diberitahukan via notifikasi aplikasi.
